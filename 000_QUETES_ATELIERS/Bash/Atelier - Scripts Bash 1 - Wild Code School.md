## Atelier - Scripts Bash 1

## Exercice 1 - Compter des lignes

## Objectif du script

Avoir un script Bash qui affiche le nombre total de lignes de 2 fichiers.

## Contraintes

- Les 2 fichiers se nomment **file1** et **file2**
- Leur nom est stocké dans 2 variables `$file1` et `$file2` données au début du script
- **file1** contient 4 lignes de texte
- **file2** en contient 6
- L'affichage de sortie est:
```shell
Le nombre total de lignes est <nombre de ligne>
```

## Aide

La commande `wc` permet de compter.
