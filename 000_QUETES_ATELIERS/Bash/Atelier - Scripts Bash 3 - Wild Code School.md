## Atelier - Scripts Bash 3

## Exercice 1 - Fonction addition

## Objectif du script

Avoir un script Bash qui fait la somme de 2 nombres et qui affiche le résultat.

## Contraintes

- Les 2 nombres sont donnés en argument du script
- On test en début de script si les 2 arguments sont bien présent. Si ce n'est pas le cas on affiche:
```shell
Il manque des nombres !"
```
- Dans le script ces 2 nombres sont stockés dans les variables `nombre1` et `nombre2`
- Une fonction `addition` est créée et utilisée
- L'affichage de sortie est:
```shell
Résultat : <Somme des 2 nombres>
```

## Aide

Les 2 variables qui contiennent la valeur des 2 nombres sont passées en argument de la fonction.  
Par exemple, pour la fonction `fonction1` les arguments `$arg1` et `$arg2` sont passés de la manière suivante: `fonction1 $arg1 $arg2`
