## Déploiement PXE avec WDS, MDT

## 🧩 Introduction

Dans cet atelier, tu vas plonger dans le déploiement automatisé de systèmes d'exploitation à travers un scénario concret: configurer un serveur Windows 2022 avec WDS et MDT, préparer une image Windows 11, et déployer cette image via le réseau en utilisant le boot PXE. Tu découvriras comment mettre en place une infrastructure complète de déploiement dans un environnement virtualisé avec VirtualBox.

## 🤓 Objectifs

✅ Installer et configurer WDS sur Windows Server 2022  
✅ Installer et configurer MDT avec Windows ADK  
✅ Importer une image Windows 11 dans MDT  
✅ Ajouter des applications dans MDT  
✅ Déployer via PXE
